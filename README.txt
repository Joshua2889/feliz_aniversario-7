# NUESTRA HISTORIA — versión romántica

Esta versión cambia el diseño a un estilo más orgánico:
- menos tarjetas y bordes cuadrados
- fotos inclinadas y superpuestas
- estética de carta de amor / scrapbook
- tipografía manuscrita Delius + serif suave
- galería aleatoria
- botón para mezclar recuerdos
- animaciones suaves
- responsive para celular

## PONER FOTOS SIN ROMPER NADA

### Galería aleatoria
Abre:
assets/fotos/

Mete tus fotos ahí con estos nombres:
01.jpg
02.jpg
03.jpg
...
30.jpg

No necesitas editar HTML ni JavaScript.

Si tienes menos de 30, no pasa nada: la página simplemente mostrará las que existan.

## IMPORTANTE
No cambies las carpetas ni los nombres de los archivos especiales.
Para la galería aleatoria usa números consecutivos.

La web puede abrirse directamente haciendo doble clic en index.html.
